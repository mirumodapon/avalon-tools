# 2.0 回歸檢查清單（對照 1.9.1）

升級到 2.0 只改架構，1.9.1 的行為都要保留。發布前在**手機**（iOS Safari 與 Android Chrome 各一）逐項確認。

## 自動化

`pnpm test`：規則、紀錄、儲存、主題、registry、`createPwaConfig`、SW 快取清理、1.x 資料搬移（fake-indexeddb）、舊網址轉址、1.9.1 備份匯入。

service worker 與升級流程沒有自動化的瀏覽器測試，以下各節需手動確認。

## 升級（裝置上已有 1.9.1）

準備：用 1.9.1（tag `v1.9.1`）建立至少一場已結束、一場進行中的遊戲，主題設為非預設（例如淺色＋桃色），名冊有人。

- [ ] 已安裝的 1.x App 開啟後自動更新，進到「阿瓦隆工具集」，出現一次升級說明卡
- [ ] 卡片「打開遊戲紀錄」進入 `/record/`；「知道了」後不再出現
- [ ] 遊戲紀錄列出全部舊遊戲，進行中的那場可以接著記錄
- [ ] 主題、預設輸入方式、強制派票、名冊、命名規則、顯示設定都和升級前相同
- [ ] 開啟時沒有閃一下錯誤的主題色
- [ ] 舊書籤 `/#/play/<id>`、`/#/summary/<id>`、`/#/settings` 轉到 `/record/` 對應頁面
- [ ] 舊分享連結 `/?s=…` 轉到 `/record/?s=…` 並正常開啟
- [ ] 舊資料仍在（`avalon-recorder:*`、IndexedDB `avalon-recorder`），預計 2.1.0 之後清除
- [ ] 模擬搬移失敗（例如儲存空間已滿）時出現「舊版資料搬移失敗」，可「匯出舊資料備份」，備份可在設定匯入

## 遊戲紀錄（`/record/`）——1.9.1 功能

- [ ] 開新局：人數、名冊挑選、角色配置、湖中女神、命名
- [ ] 派票：隊員、投票（全部／只記異常）、第 5 次強制派票自動通過（設定可關）
- [ ] 任務結果、湖中女神（分開／精簡版面）、刺殺
- [ ] 復原（含確認）、遊戲內設定（標題、備註）
- [ ] 賽後回顧表格、角色圖例、隱藏角色
- [ ] 匯出：文字、詳細文字、PNG（含存到相簿）、JSON；QR 分享與掃描
- [ ] 設定：匯出／匯入全部、清除資料只清 `avalon:record:*` 與 `avalon-record`
- [ ] 關閉 App 後重開回到原本的畫面
- [ ] 雙擊與雙指不會縮放；輸入框不會觸發 iOS 放大
- [ ] 啟動時有新版本會自動更新

## 工具集與各 App 獨立

- [ ] 首頁列出遊戲紀錄（可點）、夜晚旁白與角色發牌（即將推出，不可點）
- [ ] 資訊頁：版本、儲存空間用量與持久保存狀態、更新紀錄
- [ ] 不存在的路徑顯示 404 頁，可回首頁
- [ ] 首頁與遊戲紀錄可**分別**安裝，圖示、名稱各自不同，各自開在自己的頁面
- [ ] 在其中一個改主題，另一個（含已開啟的分頁）跟著變
- [ ] 首頁不會修改或清除遊戲紀錄的資料
- [ ] 單獨安裝的遊戲紀錄，標題左側沒有回到工具集的圖示；從已安裝的工具集進入遊戲紀錄時則有
- [ ] 兩個 App 都離線可開；只開過首頁時，離線打開 `/record/` 不會誤顯示首頁
