# 遊戲流程與名詞

這一頁說明《阿瓦隆》一局怎麼進行，以及工具裡用到的名詞。

## 一局的流程

1. **發身分**：每位玩家拿到一個角色，分成好人和壞人兩個陣營。人數與陣營的比例見[人數與出隊](./player-count)。可以用角色發牌代替實體卡。
2. **夜晚**：依角色互相確認身分，誰看得到誰見[角色與視野](./roles)。
3. **組隊與投票**：隊長提名這次任務的隊員（出隊），所有人一起投贊成或反對。
   - 贊成的人數**超過一半**，隊伍通過，去出任務。
   - 沒有超過一半，隊伍被否決，由下一位玩家擔任隊長重新提名。
4. **出任務**：隊員各自偷偷出「成功」或「失敗」。只要有一張失敗（7 人以上的第 4 次任務需要兩張），任務就失敗。可以用角色發牌的「出任務」代替卡片。
5. 重複組隊與出任務，最多五次任務。

## 勝負

- **壞人獲勝**：三次任務失敗；或某次任務的第 5 次派票（強制局）也被否決。
- **好人完成三次任務**：進入刺殺階段，刺客指定一名玩家。刺中梅林，壞人獲勝；沒刺中，好人獲勝。

## 湖中女神（擴充）

第 2、3、4 次任務結束後，湖中女神的持有者可以查驗一名玩家的陣營，之後湖中女神交給被查驗的人。曾經持有過的玩家不能再被查驗。遊戲紀錄預設 7 人以上開啟。

## 名詞解釋

| 名詞     | 意思                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 隊長     | 負責提名這次出隊的玩家。每次派票後由下一位（順時針）接任，不論隊伍有沒有通過。                       |
| 出隊     | 隊長提名去出任務的隊伍；也指隊伍的成員（「出隊人數」）。                                             |
| 派票     | 一次「提名隊伍＋全員投票」。每次任務最多五次派票。遊戲紀錄也用「派票」稱呼逐一記下贊成者的輸入方式。 |
| 派跳     | 遊戲紀錄的另一種輸入方式：預設隊內贊成、隊外反對，只點選不照預設投票的人（場外白、場內黑）。         |
| 場外白   | 不在隊伍裡，卻投**贊成**的玩家。                                                                     |
| 場內黑   | 在隊伍裡，卻投**反對**的玩家。                                                                       |
| 強制局   | 一次任務的第 5 次派票。若仍被否決，壞人直接獲勝，所以通常全員贊成。                                  |
| 好人     | <span class="faction-good">好人陣營</span>，目標是完成三次任務並保護梅林。                           |
| 壞人     | <span class="faction-evil">壞人陣營</span>，目標是讓三次任務失敗，或在最後刺中梅林。                 |
| 刺殺     | 好人完成三次任務後，刺客指定一名玩家；刺中梅林則壞人獲勝。                                           |
| 湖中女神 | 查驗一名玩家陣營的擴充道具，見上方說明。                                                             |
