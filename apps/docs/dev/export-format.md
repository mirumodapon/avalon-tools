# 匯出格式

這一頁是遊戲紀錄 JSON 匯出格式的規格，以及版本相容的規則。

遊戲紀錄的「匯出這場」選 JSON，或「設定 → 資料備份 → 全部匯出」，產生的就是這個格式；「匯入」也只接受這個格式。

## 檔案

- 單場：一個遊戲物件。
- 多場（全部匯出）：遊戲物件的陣列。
- 編碼 UTF-8，縮排 2 格。JSON 一律包含完整資料（含角色），和「呈現方式」、「包含角色」選項無關。

## 版本相容

- 每場遊戲都有 `schemaVersion`，目前是 **1**。
- 匯入時，版本較舊的資料會依序執行 `MIGRATIONS` 升級到目前版本，再驗證。
- 版本比程式新的資料無法匯入，會顯示「資料版本 N 比此版本程式更新，請先更新程式」。
- 修改格式時：提高 `SCHEMA_VERSION`，在 `MIGRATIONS[舊版本]` 加上轉換，並更新本頁的欄位說明（`apps/docs/.vitepress/data/exportFormat.ts` 的 `FIELD_DOC`；漏掉時測試會失敗）。

## 其他格式

| 格式     | 用途                                                           | 可以匯入       |
| -------- | -------------------------------------------------------------- | -------------- |
| 純文字   | 簡短摘要                                                       | 否             |
| PNG      | 歷史表格圖片                                                   | 否             |
| 分享連結 | 網址 `?s=` 參數中的精簡格式（匯出面板的「連結」與「QR code」） | 是（開啟連結） |

分享連結的格式在 `packages/record-core/src/share.ts`（`SHARE_VERSION = 1`）：玩家以座位索引表示，每次派票壓成一個整數（隊長、隊員與贊成者的位元遮罩、輸入方式），再以 deflate-raw 壓縮並 base64url 編碼，前綴 `z`（壓縮）或 `j`（未壓縮，較短時使用）。這是內部格式，請用 JSON 交換資料。
