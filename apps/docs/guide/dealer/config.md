# 角色配置

這一頁說明「發角色」分頁怎麼設定人數與特殊角色，以及配置有問題時會看到的提示。

## 玩家人數

選擇 5–10 人。下方顯示這個人數的好人、壞人數量。玩家以**座位號碼**表示，不需要輸入名字。

## 特殊角色

特殊角色分成兩組，用開關選擇：

| 陣營 | 可選的特殊角色                 | 其餘的座位     |
| ---- | ------------------------------ | -------------- |
| 好人 | 梅林、派西維爾                 | 亞瑟的忠臣     |
| 壞人 | 刺客、莫甘娜、莫德雷德、奧伯倫 | 莫德雷德的爪牙 |

每組下方會顯示「其餘 N 位為亞瑟的忠臣（或莫德雷德的爪牙）」。各角色的能力與視野見[角色與視野](../../rules/roles)。

### 依人數的預設

改變人數時，特殊角色會重設為這個人數的預設：

| 人數 | 預設開啟的特殊角色                             |
| ---- | ---------------------------------------------- |
| 5    | 梅林、刺客                                     |
| 6    | 梅林、派西維爾、刺客、莫甘娜                   |
| 7–9  | 梅林、派西維爾、刺客、莫甘娜、莫德雷德         |
| 10   | 梅林、派西維爾、刺客、莫甘娜、莫德雷德、奧伯倫 |

設定會記在手機裡，下次開啟沿用。

## 配置檢查

| 提示                                                      | 類型 | 可以發牌嗎                          |
| --------------------------------------------------------- | ---- | ----------------------------------- |
| 特殊好人（或壞人）有 N 位，但 M 人只有 K 位好人（或壞人） | 錯誤 | 不行，「超過 N 位」需要關掉一些角色 |
| 有派西維爾但沒有梅林，派西維爾沒有人可以保護              | 警告 | 可以                                |
| 沒有派西維爾，莫甘娜的能力沒有作用                        | 說明 | 可以                                |

沒有問題時按「開始發牌」。
