# 傳手機流程

這一頁說明三種模式怎麼傳手機：長按翻牌、雙擊蓋牌，以及防止偷看的設計。

## 基本操作

| 操作         | 做什麼                                      |
| ------------ | ------------------------------------------- |
| **長按**卡背 | 按住約 1 秒翻開，避免拿到手機時誤觸就翻牌。 |
| **雙擊**卡片 | 看完後快速點兩下蓋牌，交給下一位。          |
| 右上角 ✕     | 中途結束，會先確認。                        |

翻開的牌在以下情況會自動蓋上：

- 按手機的「返回」鍵（不會離開頁面）；
- 切換到其他 App 或關閉螢幕。

## 發角色

1. 在「發角色」分頁設定好[角色配置](./config)，按「開始發牌」。角色會立即隨機分配，並存進[歷史紀錄](./history)。
2. 畫面顯示「請將手機交給 N 號玩家」，從 1 號開始依座位順序。
3. 該玩家長按卡背，看到自己的角色、陣營、能力說明，以及夜晚看得到的座位號碼（例如梅林看到「壞人：2、5 號」）。
4. 確認後雙擊卡片蓋牌，把手機交給下一位。
5. 所有人都看完後，顯示「所有玩家已確認身分，遊戲開始！」。

結束畫面可以：

- **重新發牌**：用相同設定重新分配所有角色，大家要重新看一次。上一次的結果仍保留在歷史紀錄。
- **回到設定**、**查看歷史紀錄**。

中途按 ✕「結束發牌」時，結果已經保存在歷史紀錄，之後可以用「回放」讓還沒看的人繼續看。

## 出任務

用一支手機代替任務卡，每位隊員私下出「成功」或「失敗」。

1. 在「出任務」分頁選擇出任務的人數（2–5 人），按「開始出任務」。
2. 畫面顯示「請將手機交給第 N 位出任務的玩家」。
3. 該玩家長按「長按出牌」，點選「任務成功」或「任務失敗」。兩個按鈕的上下位置每個人都是隨機的，旁人無法從手指位置判斷。
4. 全部出完後顯示「所有隊員已出牌」，長按公布結果。
5. 結果顯示「任務成功」或「N 張失敗」，牌一律先排成功、再排失敗，看不出是誰出的。

::: tip 只算張數
出任務只統計失敗的張數，不會判斷任務成敗：7 人以上的第 4 次任務需要兩張失敗才算失敗，請依[出隊人數](../../rules/player-count#出隊人數)自行判斷。
:::

::: warning 注意按鈕顏色
「任務成功」與「任務失敗」的按鈕顏色不同，出牌時請遮住螢幕，避免旁人從顏色看出選擇。
:::

結果畫面可以「再出一次任務」（相同人數）或「回到設定」。

## 湖中女神

用一支手機代替陣營卡，讓湖中女神的持有者私下看被查驗者的陣營。不需要設定。

1. 在「湖中女神」分頁按「開始湖中女神」。
2. 把手機交給**被查驗的玩家**，長按後選擇要亮出的身分（好人或壞人，兩個按鈕的位置隨機）。依規則應亮出自己真正的陣營。
3. 把手機交給**湖中女神持有者**，長按查看對方亮出的身分。
4. 看完雙擊卡片蓋上，畫面顯示「湖中女神交給被查驗的玩家」。

可以「再查驗一次」或「回到設定」。
