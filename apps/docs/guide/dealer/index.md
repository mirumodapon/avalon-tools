# 角色發牌

這一頁介紹角色發牌能做什麼：用一支手機代替實體身分卡、任務卡與湖中女神。

角色發牌（`/deal/`）讓大家輪流傳一支手機，每個人私下看自己的身分；也可以用來匿名出任務牌，以及進行湖中女神的查驗。

設定頁上方有三個分頁，三種模式彼此獨立，互不影響：

| 模式     | 做什麼                                                                   |
| -------- | ------------------------------------------------------------------------ |
| 發角色   | 依人數與角色配置隨機發牌，每位玩家依座位號碼輪流看自己的身分與夜晚視野。 |
| 出任務   | 選出任務的人數，手機依序交給每位隊員出「成功」或「失敗」，最後公布結果。 |
| 湖中女神 | 被查驗的玩家選擇要亮出的身分，再交給持有者查看。                         |

- [角色配置](./config)：發角色前怎麼選特殊角色，以及配置不合理時的提示。
- [傳手機流程](./flow)：長按翻牌、雙擊蓋牌，以及三種模式的步驟。
- [歷史紀錄](./history)：每次的結果都會保存，並且先遮蔽，避免被偷看。

::: tip 和遊戲紀錄的關係
角色發牌和遊戲紀錄是兩個獨立的工具，發牌結果不會自動帶入遊戲紀錄。想用一支手機帶完整場、結束後直接交給遊戲紀錄，請用[單機遊戲助手](../assistant/)。
:::
