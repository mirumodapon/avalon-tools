# 歷史紀錄

這一頁說明角色發牌的歷史紀錄保存什麼、保留多少筆，以及怎麼在不被偷看的情況下查看結果。

在設定頁右上角開啟「歷史紀錄」。

## 保存什麼

三種模式的結果都會保存，依時間由新到舊排列：

| 模式     | 保存的內容                               | 什麼時候保存         |
| -------- | ---------------------------------------- | -------------------- |
| 發角色   | 人數、角色配置、每個座位的角色           | 按下「開始發牌」時   |
| 出任務   | 出任務的人數、失敗張數、每一位依序出的牌 | 最後一位隊員出完牌時 |
| 湖中女神 | 被查驗的玩家亮出的身分                   | 持有者看完蓋上時     |

## 保留筆數

三種模式**合計保留最近 50 筆**，超過時自動刪除最舊的紀錄，不能調整。

紀錄存在這支手機的瀏覽器裡，換手機或清除瀏覽器資料後不會保留。

## 防偷看

清單中不會直接顯示結果：

- **發角色**：只顯示人數與特殊角色。
  - **檢視**：長按一次後顯示全部座位的角色，可以切換「依座位」或「依陣營」呈現。
  - **回放**：用同一組結果再輪流傳一次手機，讓每位玩家各自重看自己的身分，不會新增紀錄。適合有人忘記身分，或發牌中途結束時。
- **出任務**：只顯示「N 人出任務」。按「檢視」後長按才顯示結果，以及每一位依序出的牌（第 1 位、第 2 位……）。
- **湖中女神**：只顯示「只有持有者看過結果」。按「檢視」後長按才顯示。

::: warning 出牌順序
出任務的檢視會顯示出牌順序，知道誰是第幾位出牌的人就能推出誰出了失敗，請只在需要時查看。
:::

## 刪除

- 每筆紀錄右側的刪除按鈕刪除單筆。
- 清單最下方的「清除全部紀錄」刪除全部，會先確認。
