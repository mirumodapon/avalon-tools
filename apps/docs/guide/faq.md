# 常見問題

這一頁回答資料存在哪裡、換手機怎麼搬、怎麼清除資料，以及更新沒有生效時怎麼辦。

## 資料存在哪裡？

所有資料都只存在**這支手機的這個瀏覽器**裡，不會上傳到伺服器。

| 資料                     | 位置                                         |
| ------------------------ | -------------------------------------------- |
| 遊戲紀錄的遊戲           | 瀏覽器資料庫（IndexedDB）                    |
| 遊戲紀錄的設定、玩家名冊 | 瀏覽器儲存空間（localStorage）               |
| 角色發牌的歷史紀錄       | 瀏覽器資料庫；無法使用時改存在瀏覽器儲存空間 |
| 主題（深淺色、強調色）   | 瀏覽器儲存空間，所有工具共用                 |

所以用不同瀏覽器（例如 Safari 和 Chrome）開啟，看到的是兩份不同的資料。安裝成 App 的工具和同一個瀏覽器共用資料。

## 換手機怎麼搬資料？

遊戲紀錄：

1. 在舊手機打開遊戲紀錄，進入「設定 → 資料備份」，按「全部匯出」，得到一個 JSON 檔。
2. 把檔案傳到新手機。
3. 在新手機打開遊戲紀錄的「設定 → 資料備份」，按「匯入」，選擇這個檔案。

詳細步驟見[保存、匯出與匯入](./record/import-export)。也可以用[分享連結](./record/import-export#分享連結)一場一場傳。

角色發牌的歷史紀錄沒有匯出功能，換手機後不會保留。

## 怎麼清除資料？

- **遊戲紀錄**：「設定 → 危險區域 → 清除所有資料」，會刪除所有遊戲、玩家名冊與設定，需要確認兩次。建議先全部匯出備份。
- **刪除單場遊戲**：在遊戲列表點該場的選項選「刪除」，或在記錄畫面開啟「遊戲設定」刪除。
- **角色發牌**：「歷史紀錄」頁最下方的「清除全部紀錄」，或刪除單筆。
- **全部工具**：在瀏覽器設定中清除這個網站的資料，所有工具的資料都會被刪除。

## 更新沒有生效？

1. 確認手機有網路，然後**完全關閉**工具再重新開啟。開啟時會檢查更新，有新版本會顯示「APP 更新中…」並自動重新載入。
2. 首頁的「資訊」頁可以看到目前的版本號碼。
3. 仍然是舊版時，等幾分鐘再試：網站更新後，伺服器的快取最多需要約 10 分鐘才會失效。

## 為什麼說明網站不能安裝？

說明會經常更新，所以刻意不做成 App，也不離線快取，每次開啟都是最新內容。工具本身可以安裝、離線使用。
