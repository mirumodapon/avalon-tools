# 整合遊戲助手

整合遊戲助手（`/assistant/`）用一支手機帶完一整場遊戲：發角色、每一輪的組隊、投票、出任務與湖中女神、刺客指認，最後把整場交給[遊戲紀錄](../record/)保存。

手機大部分時間在**當輪隊長**手上；需要私下操作時（看身分、傳手機投票、出任務、湖中女神），依畫面指示把手機交給下一位。每個傳手機的畫面都會寫出要交給誰，例如「3 號・小明」；沒有填名字的座位只顯示「3 號」。

## 開局

1. **玩家人數與角色**：和[角色發牌](../dealer/config)相同，換人數時會帶入該人數常用的角色。
2. **玩家名字（選填）**：依座位填寫，空白的座位以號碼顯示。名字會一起交給遊戲紀錄。
3. **投票方式**：
   - **傳手機投票**：從隊長開始依座位順序傳一圈，每個人長按卡片後私下選「同意」或「反對」（兩個按鈕的位置每次隨機），全部投完後長按卡片一起公布。
   - **隊長輸入**：大家照平常公開投票，由隊長輸入，方式和[遊戲紀錄](../record/voting)相同：「派票（記贊成）」點選投同意的玩家；「派跳（記異常）」預設隊員同意、其他人反對，只點選例外的玩家（場外白／場內黑）。兩種方式可以隨時切換，已點選的票會保留，下次沿用上次用的方式。
4. **湖中女神**（第 2、3、4 次任務後）：持有者選擇要查驗的玩家（不能查驗自己或曾持有過的人）後，直接長按卡片查看對方的**真實陣營**，看完雙擊蓋上；被查驗的玩家不需要操作。最後持有者**公開宣告**「好人」「壞人」或「不宣告」（可以說謊），紀錄的是這個宣告。

按「開始遊戲」後，第一位隊長由系統隨機抽出；湖中女神交給第一位隊長右手邊的玩家。接著依座位傳手機看身分，操作和[角色發牌的傳手機流程](../dealer/flow)相同：長按卡片翻開，看完雙擊蓋上。

上次的開局設定會被記住，下一場直接帶入。

## 每一輪

畫面上方是五次任務的人數與結果（需要兩張失敗的任務標示「2 敗」），以及目前是第幾次組隊；第 5 次組隊標示「強制局」。

1. **組隊**：隊長點選隊員，人數正確才能按「送出組隊」，確認後進入投票。
2. **投票**：依開局選的方式投票，公布後顯示每個人的票與「通過」或「否決」，按「繼續」記錄。
   - 否決：換下一位隊長重新組隊。
   - 強制局被否決：壞人直接獲勝。
3. **出任務**：手機依座位順序交給每位隊員，長按卡片後選「任務成功」或「任務失敗」。好人只能出成功：好人的兩個按鈕都寫「任務成功」，但顏色和位置跟平常一樣，旁人從畫面看不出是誰。全部出完後長按公布，牌一律先排成功再排失敗。
4. **湖中女神**（第 2、3、4 次任務後）：持有者選擇要查驗的玩家（不能查驗自己或曾持有過的人），被查驗的玩家私下選擇要亮出的身分，再交給持有者長按查看、雙擊蓋上。最後持有者**公開宣告**「好人」「壞人」或「不宣告」，紀錄的是這個宣告。

三次任務成功後進入**刺客指認**：選出要刺殺的玩家並確認，立即公布結果。三次任務失敗則壞人直接獲勝。

::: warning 沒有「復原」
組隊、投票、任務與刺殺一旦送出或公布就不能復原，送出前都會再確認一次。真的按錯的話，加入遊戲紀錄後可以在遊戲紀錄中[修改](../record/editing)。
:::

## 結算與加入遊戲紀錄

結算畫面顯示勝方與原因、每個人的角色，以及每次任務的隊長、隊員、否決次數與湖中女神的宣告。

按「**加入遊戲紀錄**」會在新分頁開啟遊戲紀錄的預覽，確認後按「儲存」就會加入遊戲紀錄的列表，之後可以在那邊回顧、匯出與分享。整合遊戲助手本身不保存已結束的遊戲：按「新遊戲」後這一場就會從助手中刪除。

## 中途離開

進行中的遊戲會保存在這台裝置上，重新整理或 App 被系統關掉後可以接續。

為了保密，**正在私下進行的步驟不會保存**：如果在看身分、傳手機投票、出任務或湖中女神的途中離開，回來後會從那一步的開頭重新開始，已經做過的選擇會被捨棄。

右上角的 × 可以放棄這一場，放棄後無法復原。
