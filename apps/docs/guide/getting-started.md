# 開啟與安裝

這一頁說明怎麼開啟阿瓦隆工具集、把工具安裝到手機主畫面，以及離線時能做什麼。

## 開啟網站

用手機瀏覽器開啟網站首頁，就會看到所有工具：

| 工具     | 網址       | 用途                                                   |
| -------- | ---------- | ------------------------------------------------------ |
| 遊戲紀錄 | `/record/` | 記錄每次派票、投票、任務結果與湖中女神，賽後回顧與分享 |
| 角色發牌 | `/deal/`   | 一支手機輪流傳遞，讓每位玩家看自己的身分；也能出任務   |

標示「即將推出」的工具還不能使用。

## 安裝成 App

每個工具都可以**單獨**安裝到主畫面，安裝後會像一般 App 一樣全螢幕開啟。請先打開要安裝的工具（例如遊戲紀錄），再從瀏覽器加入主畫面；在首頁安裝的是「阿瓦隆工具集」本身。

### iPhone、iPad（Safari）

1. 用 Safari 打開要安裝的工具。
2. 點下方的「分享」按鈕。
3. 選「加入主畫面」，再點「新增」。

### Android（Chrome）

1. 用 Chrome 打開要安裝的工具。
2. 點右上角的選單（⋮）。
3. 選「安裝應用程式」或「加入主畫面」。

::: warning 待確認
各瀏覽器版本的選單名稱可能不同，以上名稱需要在實機上確認。
:::

## 離線使用

- 工具打開過一次後就能離線使用，資料都存在手機裡，不需要網路。
- 每次開啟工具（或離開超過 5 分鐘後回來）會先檢查更新，畫面顯示「檢查更新中…」；有新版本時會自動更新並重新載入。沒有網路時最多等 6 秒就直接進入。
- 這份使用說明**不能離線閱讀**，每次開啟都會從網路取得最新內容。
- 在工具裡按右上角的 ? 開啟說明時，一律開在新分頁（安裝的 App 會交給瀏覽器開啟），進行中的遊戲不受影響。

## 主題

遊戲紀錄的「設定 → 主題」可以選擇淺色、深色或跟隨系統，以及強調色。所有工具與這份說明共用同一個設定：在說明網站右上角切換深淺色，工具也會跟著改變。
