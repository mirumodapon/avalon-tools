# 任務與刺殺

這一頁說明隊伍通過後怎麼記錄任務結果、湖中女神、刺殺，以及結算時怎麼填寫角色。

## 記錄任務結果

1. 畫面列出這次出任務的隊伍。
2. 在「失敗票張數」點選翻開的失敗票數量（0 到出隊人數）。
3. 下方會顯示「任務成功」或「任務失敗」，確認後按「送出任務結果」。

7 人以上的第 4 次任務會提醒「本局需要 2 張失敗才算任務失敗」：只有一張失敗時，任務仍算成功。

想讓隊員用手機匿名出牌，可以用角色發牌的[出任務](../dealer/flow#出任務)，再把結果記到這裡。

## 湖中女神

第 2、3、4 次任務後（遊戲還沒結束時），畫面會進入湖中女神，**不能跳過**。

1. 畫面顯示「湖中女神・第 N 次」與目前的持有者。
2. 在「查驗對象」選一位玩家。持有者本人和曾經持有過的玩家不能選（標示「持有者」、「持有過」）。
3. 在「宣告結果（可能說謊）」選持有者公開說的結果：好人、壞人或未宣告。
4. 按「送出查驗」。湖中女神交給被查驗的玩家。

查驗送出後不能編輯，記錯時用[復原上一步](./editing)。

## 勝負判定

工具會自動判斷：

- 三次任務失敗，壞人勝利；
- 強制局沒有通過，壞人勝利；
- 三次任務成功，進入刺殺。

## 刺殺

1. 畫面顯示「好人完成 3 個任務！」，在「刺殺目標」選刺客指認的玩家。
2. 已指派梅林時，會自動判定是否刺中；沒有指派時，在「刺殺結果」選「刺中梅林」或「沒刺中」。
3. 按「確認刺殺」。

## 結算

遊戲結束後，記錄畫面顯示勝方與原因（例如「3 個任務失敗」、「刺客沒有刺中梅林」），按「前往結算」：

- **刺殺**：可以修正刺殺目標或結果。
- **角色指派（可只填部分）**：填寫每位玩家的角色，賽後統計與歷史表格會依此顯示陣營。
- **名稱與備註**。

按「保存」完成。保存後，名稱、備註與角色仍可以在遊戲詳情頁修改。

## 瀏覽已結束的遊戲

在遊戲列表點一場遊戲，可以看到歷史表格、備註與賽後統計；右上角可以編輯名稱、備註與角色，或分享。下方有「複製為新局」和「匯出這場」。
