# 修改紀錄

這一頁說明記錯時怎麼修正：復原上一步、更換隊長，以及修改名稱、備註與角色。

## 復原上一步

記錄畫面右上角的「復原上一步」會刪除**最後一筆**紀錄，可以重複使用，一步一步往回：

- 最後一次派票（例如「任務 2 第 3 次派票」）
- 任務結果（例如「任務 2 的結果」）
- 湖中女神查驗（例如「任務 3 後的湖中女神查驗」）
- 刺殺結果

按下後會先確認「將刪除『…』的紀錄」，按「恢復」才會刪除。刪除後重新記錄正確的內容即可。

::: warning 已完成的回合不能直接編輯
目前沒有「編輯某一次派票或任務」的功能。要修正較早的紀錄，必須用「復原上一步」退回到那一筆，再重新記錄之後的內容。
:::

## 更換隊長

隊長和實際情況不同時，在選隊員的步驟點隊長旁的「更換」，選擇正確的隊長。之後的隊長會從新隊長的下一位開始依序輪替。

## 修改名稱、備註與角色

- **記錄中**：右上角「遊戲設定」，可以修改標題與備註、角色配置與指派，或刪除這場遊戲。角色資訊預設隱藏，避免被其他玩家看到，需要按「顯示並編輯角色」。
- **結束後**：在結算頁修改，或在遊戲詳情頁右上角「編輯名稱、備註與角色」。
- **刺殺結果**：在結算頁修正（保存之前）。

## 記錄到一半關掉了

以安裝的 App 開啟時，會回到關閉前的畫面與捲動位置，並保留記錄到一半的內容（選到一半的隊員、投票、失敗票數、湖中女神查驗）。每次操作後遊戲都會自動存到手機裡。
