# 保存、匯出與匯入

這一頁說明遊戲怎麼保存在手機裡、怎麼匯出成檔案或圖片、怎麼用連結與 QR code 分享，以及怎麼匯入。

## 保存

遊戲在每次操作後會**自動**存到這支手機的瀏覽器裡，不需要手動存檔。結算頁的「保存」是確認結算內容，會記下保存時間。

資料只存在這支手機，換手機或清除瀏覽器資料前請先匯出，見[常見問題](../faq#換手機怎麼搬資料)。

## 匯出一場遊戲

在遊戲詳情頁最下方按「匯出這場」，或在別人分享的紀錄預覽頁按「匯出」。

1. 選擇**格式**：

   | 格式     | 內容                             |
   | -------- | -------------------------------- |
   | JSON     | 完整資料，可匯入還原（包含角色） |
   | CSV      | 每次派票一列，可用試算表開啟     |
   | Markdown | 戰報與表格，適合 Discord 或筆記  |
   | 純文字   | 簡短摘要，適合貼到 LINE          |
   | PNG      | 歷史表格圖片，套用目前主題       |

2. 選擇**呈現方式**（派票檢視或派跳檢視）與是否**包含角色**（JSON 一律包含完整資料）。
3. 用「下載」、「複製到剪貼簿」或「分享」送出。下方可以預覽內容與檔名。

### 存成圖片

在手機上選 PNG 時，按「儲存到相簿」會開啟分享選單，選「儲存影像」即可存進相簿（網頁無法直接寫入相簿）。圖片產生期間無法調整格式與呈現方式。

## 分享連結

在遊戲詳情頁右上角或遊戲列表的選項選「分享」：

- 可以切換「文字」或「QR code」顯示；
- 「複製連結」，或用「分享」交給其他 App。

整場紀錄都壓縮在連結裡，不經過伺服器。收到連結的人打開後會看到「別人分享給你的紀錄」，可以預覽、匯出，或按「匯入到本機」。本機已有同一場時，可以選擇「覆蓋」或「另存一份」。

### 掃描 QR code

遊戲紀錄首頁右上角，以及「設定 → 資料備份」，都可以開啟相機掃描分享的 QR code，掃到後進入相同的預覽與匯入畫面。不是遊戲紀錄的 QR code 會顯示「掃描失敗」。

## 全部匯出（備份）

「設定 → 資料備份 → 全部匯出」會下載一個包含所有遊戲的 JSON 檔，檔名例如 `avalon-全部-2026-11-20.json`。

## 匯入

「設定 → 資料備份 → 匯入」：

1. 「選擇 JSON 檔案（單場或多場）」，或「貼上 JSON 內容」後按「讀取」。
2. 有問題的資料會列出「第 N 筆」與原因，並略過不匯入。
3. 和手機裡現有遊戲是同一場（相同 id）時，可以逐場選「覆蓋」或「另存一份」，也可以「全部覆蓋」、「全部另存」。
4. 按「匯入 N 場」。

匯入是一次完成的：中途失敗時不會寫入任何資料，顯示「匯入失敗，未寫入任何資料」。

支援的檔案就是遊戲紀錄匯出的 JSON（單場物件或多場陣列）。格式規格見開發者文件的[匯出格式](../../dev/export-format)。

## 遊戲名稱與命名規則

沒有自訂名稱的遊戲會依「設定 → 命名規則」的範本自動命名，修改範本會即時套用到所有未自訂名稱的遊戲。

| 佔位符      | 說明                                          |
| ----------- | --------------------------------------------- |
| `{date}`    | 遊戲日期，格式依設定；也可以寫 `{date:MM/DD}` |
| `{seq}`     | 當天第幾場（建立時決定）                      |
| `{time}`    | 開始時間 `HH:mm`                              |
| `{players}` | 人數                                          |
| `{winner}`  | 勝方（好人／壞人；未結束時為空）              |

預設範本是 `{date} 第{seq}場`。匯出的檔名使用遊戲名稱，例如 `2026-11-18_第3場.json`。
