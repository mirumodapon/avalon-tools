# 組隊與投票

這一頁說明怎麼記錄一次派票：選隊員、記錄投票，以及派票、派跳兩種輸入方式和強制局的設定。

名詞（派票、派跳、場外白、場內黑、強制局）的意思見[遊戲流程與名詞](../../rules/basics#名詞解釋)。

## 1. 選擇隊員

1. 畫面會顯示這次的隊長與需要的出隊人數。
2. 點選隊員，人數符合後按「下一步：記錄投票」。人數不符時無法繼續，按鈕會顯示「再選 N 位隊員」。

隊長記錯了可以點隊長旁的「更換」，之後的隊長會從新隊長的下一位開始依序輪替。

## 2. 記錄投票

「輸入方式」有兩種，可以隨時切換，已點選的內容不會遺失：

| 輸入方式           | 怎麼點                                                             | 適合               |
| ------------------ | ------------------------------------------------------------------ | ------------------ |
| **派票**（記贊成） | 點選投贊成票的玩家，其餘視為反對。                                 | 贊成、反對各半時   |
| **派跳**（記異常） | 預設隊內贊成、隊外反對；只點選不照預設投票的人（場外白、場內黑）。 | 大多數人照預設投時 |

- 也可以用「全部贊成」、「全部反對」一次設定。
- 畫面下方即時顯示「贊成 N / 人數」，以及送出後會「通過」還是「否決」。贊成要**超過一半**才通過。
- 新的派票會沿用上一次使用的輸入方式。「設定 → 紀錄與呈現 → 預設紀錄模式」決定新遊戲一開始用哪一種。

按「送出派票」完成。被否決時，隊長換到下一位，記錄下一次派票；通過時進入[記錄任務結果](./mission)。

## 強制局

一次任務的第 5 次派票是強制局，畫面會顯示警示；這次若被否決，壞人直接獲勝。

「設定 → 紀錄與呈現 → 強制局自動設為全員贊成」開啟時（預設開啟），強制局只需要選隊員，投票自動記為全員贊成。想逐一記錄真實的投票，請關閉這個設定。
