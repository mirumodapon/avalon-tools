# 遊戲紀錄

這一頁介紹遊戲紀錄能做什麼，以及一場遊戲從開局到結算的流程。

遊戲紀錄（`/record/`）讓記錄者在實體遊戲進行時，用一支手機依序記下每次派票、投票、任務結果與湖中女神。工具會自動判斷目前的隊長、出隊人數、是否為強制局，以及勝負。

## 一場遊戲的流程

1. **開新局**：在首頁按「開新局」，設定人數、玩家座位、第一位隊長，以及要不要用湖中女神、記錄角色。見[開局設定](./setup)。
2. **記錄派票**：選隊員、記錄每個人的投票，送出。見[組隊與投票](./voting)。
3. **記錄任務結果**：隊伍通過後，記下失敗票的張數。見[任務與刺殺](./mission)。
4. 第 2、3、4 次任務後，如果有湖中女神，記錄查驗結果。
5. 重複直到分出勝負；好人完成三次任務時記錄刺殺。
6. **結算**：確認勝方、填寫角色與備註，按「保存」。

記錯了可以[復原上一步](./editing)。結束後可以[匯出、分享](./import-export)。

## 首頁

- **進行中的遊戲**：列在最上方，點一下繼續記錄。
- **遊戲列表**：可以搜尋名稱或備註，依勝方（好人勝、壞人勝、未結束）與日期篩選。每場的選項選單有「分享」、「複製為新局（沿用玩家與角色配置）」、「刪除」。
- 右上角可以掃描別人分享的 QR code，以及進入「設定」。

## 歷史表格

每個任務一張表，欄是座位號碼，列是每次派票。可以在「派票檢視」（完整的贊成／反對）與「派跳檢視」（只看場外白、場內黑）之間切換。

進行中的遊戲預設隱藏角色，避免被其他玩家看到。
